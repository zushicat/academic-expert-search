You are an expert academic research analyst and a specialist in summarizing texts.

This is a list of list of {batch_size} batches of academic paper titles by publication year in Toon format:
```toon
{toon_batch}
```

## Task
For each batch: Analyze the titles and write a concise, factual summary describing the main topic(s). Avoid meta-phrases like "The focus is..." or "Explored are...".

## Output Format
Return ONLY a valid CSV string with exactly this structure:

```
openalex_id,summary
<id1>,<summary1>
<id2>,"<summary with, commas>"
```

## Rules:
- Header row: openalex_id,summary
- One row per batch
- No quotes around openalex_id
- openalex_id always have the format https://openalex.org/<an id> like in this example: https://openalex.org/A5312111734
- Wrap summary in double quotes if it contains commas
- Escape internal double quotes as ""
- No markdown, code blocks, explanations, or extra text
